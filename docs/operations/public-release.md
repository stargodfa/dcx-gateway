## 使用方式

公开源码中不存放 `config.dev.yaml`。本地运行前从模板复制并自行填写；公开检查时需将本地配置移出待公开目录，扫描器会检查被 Git 忽略的文件。

```bash
python scripts/check_public_release.py
```

脚本检查 RFC1918 内网地址、个人路径、非示例邮箱、常见密钥形式、非占位凭据、bcrypt hash、数据库导出及不透明生成文件。`127.0.0.1`、`localhost`、文档保留地址与 `example.com` 等示例域名可以保留。第三方 Swagger UI 分发文件保留原样及其版权信息。

systemd 模板使用通用 `dcx-gateway` 服务账号和 `/opt/dcx-gateway`、`/opt/dcx-gateway-docs` 目录。部署前自行创建账号、目录并设置权限，或按本地环境修改模板。脚本中的 SSH 目标由参数指定，不包含实际机器账号或地址。

本次只清理了工程文件，没有连接或修改任何现场数据库，也没有撤销已经发放的凭据。原凭据若仍在使用，应在对应服务中更换。
